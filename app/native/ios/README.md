# iOS: Game Center saved games

The game backs its save up to the player's iCloud through Game Center saved games. The web side is
`backupNow()` / `checkBackups()` in `defender/index.html`; the bridge is `window.native.saves` in `app/src/native.js`;
the native part is the two Swift files here. They can't go in automatically because `app/ios` is generated by
`npx cap add ios`, so add them once after that:

1. In Xcode, drag `GameSavesPlugin.swift` and `ViewController.swift` into the **App** group (tick "Copy items" and the App target).
2. Open `Main.storyboard`, select the Bridge View Controller, and in the Identity inspector set **Class** to `ViewController`
   (module: App).
3. App target → **Signing & Capabilities** → add **Game Center**, and add **iCloud** with **iCloud Documents** ticked and a
   container (Xcode offers `iCloud.com.whydad.defender`).
4. In App Store Connect, turn on Game Center for the app.
5. Build on a device signed in to iCloud and Game Center. The first launch signs in (Game Center shows its banner or sheet);
   saves go up at most once a minute while playing.

What players see:
- **New phone, same Apple ID:** the game starts, finds the iCloud copy has more progress than the new empty game, and loads it.
- **Two copies with progress:** a card asks which to keep ("Use the other one" / "Keep this one").
- **Not signed in to Game Center:** the save still has a copy in the phone's own storage (Capacitor Preferences), and a
  grown-up can move it with a save code (Settings → 👪 → Saved game).

Known GameKit quirk: on the very first launch after installing, saved games can take until the second launch to appear.
Android keeps the phone copy and the save code; Google Play Games saved games would be the equivalent there.

## Achievements and leaderboards

The game reports these through the same plugin (`achieve`, `score`, `dashboard`; the bridge is `window.native.gc`).
Create them in App Store Connect → the app → **Game Center**, with exactly these IDs. There are 21. Every achievement is one step
(reported at 100%), so any point value works; Apple allows up to 1,000 points in total.

| Achievement ID | Name | Earned by |
|---|---|---|
| `whydad.ch1` … `whydad.ch8` | The Backyard, done … The Night Sky, done | Finishing each chapter |
| `whydad.why` | The Big Book of Why | Beating Sir Ever-So-Sure |
| `whydad.facts25` | Curious | Learning 25 facts |
| `whydad.facts75` | Investigator | Learning 75 facts |
| `whydad.factsall` | Fact Finder | Learning every fact |
| `whydad.friends10` | Backyard Club | Meeting 10 friends |
| `whydad.friendsall` | Everybody Home | Meeting all 28 friends |
| `whydad.stars10` | Perfect Ten | Three stars on 10 stages |
| `whydad.endless10` | Still Standing | Reaching wave 10 in the Endless Stacks |
| `whydad.master1` | Myth Master | Clearing a stage on Myth Master |
| `whydad.masterch` | Master of a Chapter | Clearing a whole chapter on Myth Master |
| `whydad.club5` | Pillar of the Club | Reaching club level 5 |
| `whydad.cup` | Myth Cup Champion | Winning a weekly Myth Cup |
| `whydad.legend` | Forged a Legend | Forging something Legendary |

Leaderboards (classic, "high score is best", integer):

| Leaderboard ID | Name | Score |
|---|---|---|
| `whydad.endless` | Endless Stacks | Best wave reached |
| `whydad.facts` | Fact Finders | Facts learned |

Each needs a name, a description (shown before and after earning) and a 512 × 512 or 1024 × 1024 image. The emoji in the
game's Trophies list (Challenges → 🏆 Trophies) are a starting point for the images. On the web, trophies show as
toasts and in that same list.
